# Zheng Sun — academic homepage

A build-free, self-contained static website for GitHub Pages. English first edition, based on the user's approved content and layout selection.

## Edit

- `index.html`: profile, projects, publications, and experience.
- `style.css`: responsive layout and visual styles.
- `assets/`: portrait, project media, conceptual research diagrams, and Chinese CV.

No package installation, JavaScript, analytics, external fonts, or runtime service is required. All links use relative asset paths, so the page works at either a user site or a project site path. Video playback uses native accessible browser controls.

## GitHub Pages

Upload the contents of this directory to the intended repository. In Settings → Pages, choose Deploy from a branch and select the repository's branch and `/ (root)` directory. The `.nojekyll` file keeps the site as plain static files. No repository or public deployment was created during preparation.

Before publishing, review the supplied Chinese CV (including its phone numbers and internship intention). Submission labels reflect the user's stated ICRA/ICLR status, not conflicting older public project metadata. The education labels follow the user's requested Robotics wording.
